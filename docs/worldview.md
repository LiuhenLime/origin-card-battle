## 3. 卡牌设计原则

- **费用曲线**：1 费 ≈ 2 点总属性，每 +1 费 ≈ +2 点总属性；战吼/嘲讽/法术强效按约 2~4 点属性折价。
- **角色卡**：世界观里的角色 → 随从（写清楚 who / atk / hp / 是否嘲讽 / 战吼）。
- **事件卡**：世界里的法术、科技、事件 → 法术（效果原语表达）。
- **传说卡**：世界观的终极存在，用大身材或唯一效果表达（每卡组 1 张）。
- 命名风格统一；`text` 字段写玩法描述，长篇风味文案放到本文件的「卡牌图鉴」。

## 5. 替换示例卡的步骤

1. 按上面的原则在 `data/cards.json` 写新卡（保留 `id` 唯一）。
2. `npm run dev` 实测手感，调费用曲线。
3. 删除不再使用的示例卡条目。
4. 提交：`git commit -m "卡牌: 替换xx阵营第一批卡"`。
